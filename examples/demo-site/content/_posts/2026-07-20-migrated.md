# Migrated from a vdoing tree

Its `date:` is **unquoted**, which is what vdoing's own writer produces and what
an existing tree is therefore full of. YAML resolves an unquoted timestamp to a
date value rather than a string, so this file and the quoted-date posts beside
it are two different types in one tree — which is exactly the mix any index that
sorts by date has to survive.
