# Relocated identity

This article's Simplified Chinese variant lives in a *different* directory
(`02.Notes/10.Local/`), joined to this identity by an explicit `permalink:`.

That is mechanism 2 from §6.2, and it is exactly why v2.1's M2 correction was
needed: with variants in two directories, "the directory path" names two
different things, so categories and the sidebar slot come from the **primary**
variant — this file — with a `doctor` warning recording the split.
