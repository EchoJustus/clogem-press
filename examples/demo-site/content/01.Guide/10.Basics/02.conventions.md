# Conventions

Three files share this number and this title, so they are **one** article with
three language variants — not three sidebar entries, and not a duplicate-number
error. That scoping is v2.1's M1 correction.

This file deliberately ships with **no front matter at all**, so `bb build`
exercises the "insert a fresh block" path of the surgical writer.

## Numbered directories

Level 1 numbering is optional; below that it is required.

## Language suffixes

The suffix test is closed over the configured `:langs` set, so `03.Vue.js.md`
still parses as a file titled `Vue.js`.
