# Containers

All eight vdoing containers, nested, inside a list item, inside a code fence,
and around a heading (D-P2-10). Default titles come from the page language —
compare the `zh-Hans` variant.

::: note
A note.
:::

::: tip
A tip.
:::

::: warning Custom title
A warning with a custom title.
:::

::: danger
Danger.
:::

::: details
Hidden until opened — works without JavaScript.
:::

::: theorem
A theorem.
:::

::: right
Right-aligned.
:::

::: center
Centered.
:::

## Nesting

:::: warning Outer
Outer body.

::: tip Inner
Inner body.
:::

Still outer.
