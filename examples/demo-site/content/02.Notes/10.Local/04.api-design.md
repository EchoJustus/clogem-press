# Hyphenated slugs are not language tags

The filename is `04.api-design.md`. Under the Phase 1 rule any hyphenated two-
or three-letter word in the last dot-segment was treated as a misspelled
language code and the build hard-errored; the rule is now confusables, an edit
distance of one from a configured code, or a configured primary subtag followed
only by script- or region-shaped subtags (DESIGN.md §6.1, D-P2-14).
