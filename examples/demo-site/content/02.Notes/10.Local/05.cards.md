# Card lists

`cardList` and `cardImgList` parse a YAML body into a card grid (D-P2-10).
Every `link` goes through the link rewriter, so a permalink lands on the
reader's language variant and a root-relative image carries the site base.

::: cardList 2
```yaml
- name: Conventions
  desc: The three-variant article, linked by permalink.
  link: /pages/643259/
  bgColor: '#3eaf7c'
  textColor: '#ffffff'
- name: Tamil only
  desc: Linked to its bare identity URL.
  link: /pages/171a98/
- name: External
  desc: Opens in a new tab by default.
  link: https://github.com/EchoJustus/clogem-press
```
:::

::: cardImgList 3
```yaml
config:
  imgHeight: 80px
  lineClamp: 2
data:
  - name: Demo image
    desc: A root-relative asset path that must carry the site base.
    img: /assets/demo.png
    link: /pages/c4d33p/
    author: demo
```
:::
