# Highlighted code

Every fenced block is highlighted by Chroma at build time (DESIGN.md §11.3
item 10). Line numbers are drawn by CSS, so they are never copied and never
indexed: a search for `result` finds this page. The copy button appears only
where the browser offers the clipboard API.

## Highlighted lines

` ```js{1,3-5} ` highlights lines 1, 3, 4 and 5:

```js{1,3-5}
import { search } from "./search.js";

const result = await search("clogem");
if (result.hits.length === 0) {
  console.log("no hits");
}
```

A space before the braces works too, ` ```clojure {2} `:

```clojure {2}
(defn greet
  "Say hello."
  [name]
  (str "Hello, " name))
```

## Without line numbers

` ```bash:no-line-numbers `:

```bash:no-line-numbers
# fetch, verify and cache Chroma, then print its path
bb fetch-tool --tool chroma
```
