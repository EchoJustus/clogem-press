# Wide content on a narrow screen

The §6.9 wrapping check: at a 360 px viewport, a long code line, a long
inline code span and a table wider than the screen must each scroll inside
their own box, never widen the page.

## A long code block

```clojure
(def a-line-of-code-far-wider-than-a-phone {:search {:provider :pagefind} :tools {:pagefind {:version "1.5.2" :cache-dir ".tools"}} :theme {:fonts {:tamil :self-hosted}}})
```

## A long inline span

The cache lives at `$XDG_CACHE_HOME/clogem-press/tools/pagefind/1.5.2/x86_64-unknown-linux-musl/pagefind_extended`, outside the site.

## A wide table

| Language | `<html lang>` | Pagefind index | Stemming | UI strings | Segmentation |
|---|---|---|---|---|---|
| English | `en` | `en` | Snowball English | built in (`en.json`) | whitespace |
| Simplified Chinese | `zh-Hans` | `zh-hans` | none | built in (`zh.json`) | jieba, Simplified dictionary |
| Traditional Chinese | `zh-Hant` | `zh-hant` | none | built in via `lang="zh-TW"` (`zh-tw.json`) | mostly single characters |
| Malay | `ms` | `ms` | none | clogem-press `:search/…` strings | whitespace |
| Tamil | `ta` | `ta` | Snowball Tamil | built in (`ta.json`) | whitespace |
